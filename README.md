# Путешествие — документация проекта

Рабочая документация атмосферной исследовательской игры о маленьком бесформенном существе и огромном космическом корабле-заводе.

## Документы

- [Сводный документ проекта](docs/project/project-continuity-ru.md) — концепция, игровой цикл, художественное направление, текущее состояние разработки и открытые вопросы.
- [Дополнение: скачок и регенерация](docs/design/jump-and-regeneration.md) — отдельная механика перехода между циклами; гипотезы и вопросы, которые пока не считаются решениями.
- [Игровой опыт и взаимодействия](docs/design/gameplay-and-player-experience.md) — исследование, сенсорные механики, звук, вибрация и луч.

## Статусы решений

В документах различаются:
- **Зафиксировано** — направление, которое уже принято в обсуждении.
- **Гипотеза** — возможное объяснение или вариант, требующий проверки.
- **Открытый вопрос** — решение ещё не принято.

Документация отражает состояние обсуждений на 17 ноября 2026 года. Это рабочая база, а не окончательное техническое задание.
